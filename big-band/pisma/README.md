# «Письма, которые мы не отправили»

Баллада и свинг для солирующего тромбона и биг-бэнда — оригинальная композиция
в духе поп-баллады из присланной партии (тональность Des-dur, солирующий
тромбон 1), но длиннее, гармонически плотнее и с ритмическими импровизациями.

## Состав (17 партий)
Альт-сакс. 1–2 · Тенор-сакс. 1–2 · Баритон-сакс. · Трубы 1–5 · Тромбон 1 (соло) ·
Тромбоны 2–3 · Бас-тромбон · Гитара (соло) · Фортепиано · Бас-гитара · Ударные

## Форма (83 такта)
| Такты | Раздел | Что происходит |
|---|---|---|
| 1–4 | Intro, rubato ♩=66 | Фортепиано соло, вступают саксофоны, затакт тромбона |
| 5–12 **A** | Slow Ballad ♩=72 | Тема тромбона; пэды саксофонов |
| 13–20 **B** | | Вариация темы; вступают тромбоны 2–3 и бас-тромбон |
| 21–28 **C** | Бридж | Трубы с сурдинами (cup); E°7, Bb7(♯5) |
| 29–37 **D** | Реприза | Орнаментированная тема (16-е, триоли), открытая медь; такт 37 — переход, сбивка ударных |
| 38–53 **E** | Double-time Swing ♩=144 (♩=♩) | 16 тактов соло тромбона ad lib. по сетке; выписан образец соло; walking bass; фоны саксофонов с 46 т. |
| 54–61 **F** | Shout chorus | Tutti: синкопы, антиципации, триоли, фолл в конце |
| 62–69 **G** | Trades по 2 такта | Тромбон → ударные → гитара → ударные |
| 70–71 **H** | Stop-time | Ритмические акценты tutti, rit., фермата |
| 72–79 **J** | Tempo I, Ballad в D-dur | Модуляция на полтона вверх, кульминация (Bb⁷♯11 → D) |
| 80–83 Coda | | Каденция тромбона ad lib., финальный Dmaj9 |

## Файлы
- `out/score.pdf` — транспонированная партитура (A3)
- `out/parts-*.pdf` — партии (A4), уже в строе инструмента
  (`a1 a2 t1 t2 bari tp1…tp5 tb1 tb2 tb3 btb gtr piano bass drums`)
- `out/pisma-demo.mid` — MIDI-демо (без гитары и ударных, свинг не «раскачан»)
- `score.ly`, `parts.ly`, `midi.ly` — исходники LilyPond
- `gen.py` — генератор: мелодии и линии лидеров написаны вручную, голоса
  секций (4-way close / drop-2), партии тромбонов, бас и фортепиано
  гармонизуются по аккордовой сетке

Пересборка: `python3 gen.py && lilypond -o out/score score.ly && lilypond -o out/parts parts.ly && lilypond -o out/midi midi.ly`

## Заметки для репетиции
- Соло-эпизоды (E, G) — импровизация; выписанные ноты — образец для
  учеников, опытный солист играет по аккордам.
- Фортепиано: выписанные голосоведения — ориентир, комп ad lib.
- Гитара и ударные в слэшах; ритмические слэши со штилями — играть вместе
  с ансамблем (shout, stop-time).
- Трубе 1 в shout и финале нужны c³–cis³ (written); при необходимости — 8vb.
